# Validação

O conjunto de testes verifica a sequência de atendimento, os destinos, os prazos das reservas, o retorno para nova data, as credenciais, o MFA, o bloqueio administrativo e a separação do suporte em sala.

Também verifica as referências dos tópicos, os quatro snapshots e a equivalência do desenho aprovado. A interface oferece busca, zoom, movimentação, exportação e visualização adaptada a diferentes larguras de tela.
